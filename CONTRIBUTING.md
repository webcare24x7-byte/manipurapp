# Contributing to ManipurApp

Thank you for contributing to ManipurApp.

## Development principles

- Preserve existing working behaviours unless a change explicitly requires them.
- Keep modules isolated and tenant-aware.
- Prefer plain PHP and the existing application architecture.
- Validate PHP syntax before submitting changes.
- Do not commit credentials, private customer data, production databases or generated secrets.

## Pull requests

Explain what changed, why it changed, and how it was tested. Include screenshots for significant UI/UX changes when useful.
