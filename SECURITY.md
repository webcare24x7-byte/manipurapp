# Security Policy

Please do not publish security vulnerabilities, credentials, API keys or private user data in public issues.

For a security-sensitive issue, contact the project maintainers privately with a description, affected component and reproduction details where possible.

Before deploying ManipurApp publicly:

- change demo credentials;
- configure production database credentials outside source control;
- configure production API keys securely;
- restrict `/install/` after installation;
- remove development/debug tools;
- use HTTPS.
